# MirrorVille login assets

Exported from the team's [Cal Hack UI deisign](https://www.figma.com/design/Meypech1vVxgjSMMi8zckU/Cal-Hack-UI-deisign?node-id=0-1), 2026-10-24, through Figma design context. Original PNG source assets are retained, including transparent margins. The composed reference screenshot is not used in the application.

`src/LoginScreen.tsx` composes these layers with native HTML controls. `src/login.css` preserves reference-stage geometry on desktop and adapts the composition on portrait screens. Typography: locally hosted Pixelify Sans, whose license is in `public/fonts/PixelifySans-OFL.txt`.
# Delivery variants

The original six Figma PNGs remain unchanged. Runtime uses WebP delivery copies generated by
`python scripts/optimize-login-assets.py` (Pillow + fontTools with Brotli support). Desktop copies
total 597,622 bytes; the password-frame copy is no longer rendered. On screens at most 600px wide,
only `village-mobile.webp` (85,162 bytes) and `logo-mobile.webp` (35,638 bytes) are requested;
decorative field/signboard/button images use an empty responsive source and CSS-native controls.
The mobile form uses normal flow instead of overlapping absolute art slots. The email-link
explanation is plain text, not a second input frame. WOFF2 font delivery is embedded in generated
`src/pixel-font.css` to avoid an extra font round trip; original font and OFL terms are retained.
