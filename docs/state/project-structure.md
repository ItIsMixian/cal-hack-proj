# Project structure

As of commit `0d59463` (2026-10-24). Facts from the code; gaps listed at the end.

## Layout

| Path | What it is |
| --- | --- |
| `spacetimedb/src/index.ts` | The whole backend module: tables, tick, conversations, postcards, Mirror Room, views, admin |
| `spacetimedb/src/world.ts` | Town layout (6 places), intent → place keywords, activities, daily events, venue clock (UTC-7) |
| `spacetimedb/src/tipi.ts` | TIPI questionnaire, scoring, self-card sentence |
| `spacetimedb/src/redact.ts` | Redaction, facets, rooms, default visibility (`isVisibleIn`) |
| `spacetimedb/src/llm.ts` | Raw HTTP calls: DeepSeek chat, Claude Messages, JSON parsing |
| `src/App.tsx` | Page shell: header, map, side panel tabs (Town / Postcards), Mirror Room page switch |
| `src/WorldCanvas.tsx` | Canvas renderer with smoothed movement, names, activities, speech bubbles |
| `src/CreateMirror.tsx` | Make-a-mirror form (name, color, TIPI, on-mind, intent) |
| `src/MirrorRoom.tsx` | Mirror Room page: portrait, facet cards, room chips, personal cards, import, add card |
| `src/Postcards.tsx` | Postcard list/detail, wave, private human chat |
| `src/importers.ts` | WhatsApp export parser, own-lines extraction |
| `src/module_bindings/` | Generated by `spacetime generate`; do not edit |
| `scripts/set-keys.mjs` | Stores model keys (hidden prompt, HTTP with admin token) |
| `.agents/skills/orrery-docs-local/` | This documentation system's skill and reader builder |

## Backend tables

Public: `mirror`, `conversation`, `line`. Private: `config` (keys, admin), `mirror_profile` (owner,
self-card), `relation` (pair sightings/talks/notes), `encounter` (postcards, waves), `human_message`,
`mirror_card`, `import_status`, plus scheduled `tick_timer`, `llm_job`, `import_job`.
Per-visitor views: `my_mirrors`, `my_postcards`, `my_human_messages`, `my_cards`, `my_imports`.

## Implemented

- Five demo mirrors seeded on init; visitors create up to 3 mirrors each, 60 total.
- Daily rhythm, visible activities, extraversion-weighted initiative, relationship sightings/talks,
  conversation length by familiarity, natural endings (`[END]`).
- Postcards per 0004 with server-side evidence check; waves; private chat.
- Mirror Room per 0005; only venue-visible cards reach prompts.

## Known gaps

- Only the venue room is live; teammates and old-friends rooms are visibility settings only.
- No triadic referral, journal postcards, group conversations, or Messenger/36-questions import.
- Not deployed publicly; runs on the dev machine (see HANDOFF and proposed-public-deployment).
- Changing table columns requires `--delete-data`, which wipes everything including keys.
