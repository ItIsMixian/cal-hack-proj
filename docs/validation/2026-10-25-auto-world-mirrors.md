# 进入世界自动创建分身验证

日期：2026-10-25。用户明确要求：已有 AI 分身原型的用户进入新世界时，自动生成该世界的独立分身。此前要求每个世界手动创建的实现被本轮需求取代；独立模拟仍保留。

## 实现范围

- 私有 `mirror_prototype` 以身份为主键，保存基础姓名、外观、selfCard 人格、外向程度和初始意向。新用户首次创建时保存；已有用户惰性补建，从自己的非 demo 分身中按最小 ID 选择稳定来源，不将 ID 顺序等同创建时间。
- `activateWorld` 在事务内校验成员身份，确保目标世界存在自己的分身，再更新查看选择。新建世界、邀请加入、开放加入和切换已有世界共用该逻辑。
- 目标世界已有自己的分身时直接复用；包括停用记录，不因为进入就绕过管理员停用决定。无原型用户仍走首次创建问卷。
- 自动创建只产生一个新 ID 的居民，独立出生位置与运行状态；不移动源分身、不结束它的对话。新分身不复制联系方式、导入卡片、摘要、日记、关系、对话或行为进度。
- 原型为基础设定快照，各世界后续修改不回写原型，不同步到其他已有或后续世界。当前没有独立的原型编辑界面。
- 容量不足时拒绝创建／进入；真实事务会整体回滚，不能通过自动创建绕过世界权限和居民容量。浏览不存在世界的入口窗口不触发创建。

## 实际结果

- `scripts/start-local-worlds.ps1` 成功向本机 `mirrorville-worlds-test`（127.0.0.1:3010）发布。迁移计划只新增私有 `mirror_prototype` 表，使用 `--delete-data=never`；既有世界、成员和分身保留。原共享数据库未修改。
- `npm.cmd run build`：TypeScript 和 Vite worldtest 构建成功。
- `npx.cmd tsc --noEmit -p spacetimedb/tsconfig.json`：通过。
- 相关单元测试合并执行 88 项全部通过：Diary 49（其中实际后端回调 25）、roaming 7、fidelity 12、importers 10、auth 10。新增自动生成回归验证稳定原型补建、重复进入幂等、新用户首次创建、其他身份隔离、权限／容量／停用处理；原世界运行与数据隔离回归仍通过。
- `npm.cmd run test:worlds:live` 真实 SDK 8 组检查全部通过：权限与名额、世界订阅及 8 张私表 SQL 拒绝、自动分身与联系方式往返独立、主人离开后的持续移动、重连保留、邀请加入自动创建、新建世界自动创建、并发最后名额。
- 关键 live 路径：A 在私人世界手动建立原型分身 X；进入从未创建自己分身的大厅，订阅自动出现同姓名／外观的新分身 Y，ID 不同且联系方式为空。重复进入仍仅一个 Y。修改 Y 的意向和联系方式，再返回 X，确认 X 不变；加入第三个邀请世界自动出现 Z，仍使用原型初始意向而非 Y 的世界修改。D 已有原型后新建世界，也自动获得独立居民。
- live 检查同时观察到 X 在 A 停留大厅时继续移动；后台持续模拟逻辑保留。
- `git diff --check` 通过，根目录及子仓库文档阅读页重新构建。

## 边界

真实 AI 密钥仍未配置，本轮自动生成指创建分身数据与模拟实体，不调用模型生成新人格。未额外进行浏览器端问卷流程或原型编辑 UI 测试；客户端继续使用已验证的 my_mirrors 订阅显示当前世界分身。既有 Status card 测试的历史失败不属于本轮相关套件。合成身份测试留下带 QA 后缀的测试记录；未删除用户数据，未提交或推送。
