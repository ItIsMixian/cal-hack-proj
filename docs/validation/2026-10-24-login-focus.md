# 登录邮箱框聚焦样式修复

日期：2026-10-24（America/Los_Angeles）。本机验证；本记录维护于应用子仓库。

## 原因与修改

原页面始终只有一个邮箱 input。桌面使用图片绘制邮箱边框，真实 input 位于图片内部；`src/login.css` 原有的 input `:focus-visible` outline 在聚焦时额外绘制较小的矩形，形成“又出现一个输入框”的视觉问题。

改为在聚焦时给既有边框图片增加阴影高亮，移除真实 input 的独立 outline；手机布局直接加深现有边框并使用内侧阴影。按钮保留键盘焦点轮廓。

## 实际验证

- 本地 Vite / 浏览器桌面：点击并输入测试邮箱后仍只有 1 个 input；outline 为 none，原边框图片高亮，无独立内侧矩形。见[聚焦截图](login-focus-assets/desktop-focused.png)。
- 键盘：Tab 从邮箱到 Login，按钮轮廓可见，图片高亮取消；Shift+Tab 返回邮箱时焦点提示恢复。
- 浏览器 390 × 844：手机媒体查询生效，1 个 input，原边框变深，内侧阴影生效；文档宽度 390，无横向溢出。非实体手机／软键盘测试。
- `npm.cmd run build`：通过。
- `npm.cmd run test:auth`：10/10 通过；认证服务与 SDK 使用既有模拟边界。

本次未测试真实邮箱验证、第三方认证服务或其他浏览器。该修改仅调整登录页焦点样式。
