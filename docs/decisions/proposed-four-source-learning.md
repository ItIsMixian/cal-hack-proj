# Four sources for a mirror's background and recent life

Status: Owner-authorized implementation (2026-10-24), unnumbered for teammate review. Extends the
source side of 0005/0006; does not change principles or the real-human endpoint.

The primary desk sources are direct observation by a Mirrorville desktop companion, public GitHub projects/activity,
an introduction from an AI the owner already knows, and the owner's deliberate update/writing.
Social-media API availability is not a dependency of this flow. The existing optional Facebook
adapter remains under the writing source's Other sources disclosure. Existing Marglo-package
imports are secondary compatibility there, not the primary desktop flow.

These sources enter one scene-first paper flow with editable local review and explicit handoff to
the existing owner-authorized import pipeline. Source, date and uncertainty are kept in the letter.
Opening the source chooser never fetches activity or submits material. AI/manual drafts survive
switching sources within the open paper; external-source adapters close on Back.

Marglo's observation idea is adapted into an independent optional Windows helper in `desktop/`,
not copied wholesale or made a runtime dependency. The helper starts paused. An exact-origin,
exact-host loopback bridge with pairing-code and memory-only bearer authorization lets the owner
enable/pause observation, review live tentative clues, clear them or disconnect. Known editor
workspace/document labels are derived locally; browser page topics require a separate opt-in.
Raw window titles, paths, URLs and Marglo's own memoir/persona are not transported as the owner's
identity. Labels may still contain untagged names or sensitive meaning, so the owner must remove
those details in the editable preview. No keystrokes, clipboard, screenshots or page bodies.
Closing the browser does not stop an explicitly enabled helper; pause or quit it to stop.
Observations require owner review before cloud handoff; automatic capture is not automatic sharing.
GitHub public lookup requires an explicit ownership declaration, not a claim
of OAuth-verified identity; repository ownership/activity cannot prove a skill or project outcome.

Imported package/GitHub material uses facts mode, not voice learning. Existing own-writing and AI
summary distinctions remain. No new database schema or backend publication is needed for the
adapters. Desktop capture runs while the helper is enabled, and local candidates refresh while the
paper is open. Cloud import still requires an explicit reviewed handoff. The owner's request
authorizes this optional local helper despite the earlier weekend native-app scope constraint;
principles remain unchanged.

Photo understanding and audio transcription are not implemented in this revision. The fourth route
currently accepts text and supported writing/chat files; no nonfunctional media button is shown.
Portfolio descriptions can be handed over as writing; arbitrary portfolio-site crawling is not added.
