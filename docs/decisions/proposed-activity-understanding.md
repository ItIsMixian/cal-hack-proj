# Local activity memory and contextual understanding

Status: owner-authorized implementation, 2026-10-25; unnumbered, no shared-principle rewrite.

The owner rejected application-usage labels as insufficient and explicitly requested Marglo's
existing full chain: window titles, episode memory, model interpretation, and continuity with the
person's background. The old application-only observer is not evidence that this is implemented.

Adapt the chain from Marglo's window observer / episode normalizer / context recall / model loop.
Keep the existing independent Mirrorville desktop app and sampler; do not import Marglo's personal
database, persona, memoir, keys, UI or self-modifying agent. Add reduced title capture, durable local
episodes, owner-scoped private understandings and an owner-authenticated DeepSeek procedure using
the town's existing configured provider. This implementation is a deliberate desktop scope extension.

Original titles remain transient. Reduced titles may be retained in the protected local observer
database because the owner explicitly requested episode memory. Do not store those titles in the
shared game database. Model interpretation is separately initiated: preview the exact title
moments, ask manually, or enable a clearly labelled automatic DeepSeek option. Automatic model
processing defaults off; capture still starts paused after every app restart.

Model updates are tentative and private. Exact evidence references are mandatory; owner corrections
and confirmations survive restart and feed subsequent understanding. Dismissed suggestions are
retained as corrections. Only an explicit confirmed-update handoff enters the existing redacted
facts import; no observation automatically becomes a shared card or a speaking-style example.

Implementation boundaries and limits are in [activity understanding](../design/activity-understanding.md).
