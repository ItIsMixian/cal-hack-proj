# 0006 Marglo is one data source among many

Status: Accepted (2026-10-24). Not implemented.

Marglo (the owner's earlier personal project) is not "the answer to what you've been doing lately";
WhatsApp, the 36 questions and other sources provide that too. What is worth borrowing from Marglo is
its long-term understanding of who you are (the core facet) and the idea of a room where you see how
the AI understands you, which became the Mirror Room (0005).

If a Marglo import is built, it arrives as one more source in the Mirror Room, through the same
redaction and card pipeline, and Devpost must state which parts existed before the event.
